# my little boat · AI Indie Pattern Adoption — 2026-08-24

```yaml
status: USER_DIRECTED_ADAPTATION
work_mode: PLAN_AND_SLICED_IMPLEMENTATION
runtime_ai: REJECT_CURRENT
core_session: mood -> 3/4 boat diorama -> rest/interact -> 5-minute voyage -> discovery -> record/album/boat memory
combat_failure_competition: FORBIDDEN
online_scope: DELAYED_BOTTLE_ONLY_AS_APPROVED
human_validation: NOT_RUN
```

## 결론

이 프로젝트의 가치는 위험 최적화가 아니라 **작은 보트 디오라마에서 내 캐릭터·펫과 쉬며 작은 발견과 기억을 쌓는 감정 경험**입니다. 따라서 `RNG_AGENCY_AND_RECOVERY`나 runtime 생성형 AI를 그대로 넣지 않습니다.

이번 흡수는 `Human-directed AI production`, `Breadth-after-core`, `AI-visible-output quality`, `player-feedback rebuild`, 그리고 승인된 **Bondee-inspired personal-space / delayed-bottle social**을 rest-first 보호선 안에서 제한적으로 활용하는 데 집중합니다.

## 핵심 Gate · CALM_CORE_BEFORE_CONTENT_BREADTH

AI로 수십 개의 풍경·편지·소품·동반자 반응을 만드는 것은 쉽지만, 핵심 공간이 편안하고 기억에 남지 않으면 콘텐츠 수가 문제를 해결하지 않습니다.

```text
오늘의 마음 선택
→ 3/4 보트 디오라마
→ 보이는 Avatar + Pet과 쉬기
→ 바다/파도 + 선택형 작은 행동
→ 약 5분 항해
→ 작은 발견
→ 오늘의 항해 기록
→ 앨범/보트에 기억이 남음
```

다음이 Human evidence로 확인되기 전에는 breadth를 성과로 취급하지 않습니다.

- 첫 30초에 조작 없이도 머물고 싶은가.
- Avatar + Pet + Boat + Sea가 모바일 세로에서 편안하게 읽히는가.
- 5분이 짧게 느껴지는가, 지루하게 느껴지는가.
- 사진/편지/풍경 발견이 체크리스트보다 기억으로 남는가.
- mood 선택이 플레이 경험의 톤에 작은 차이를 만드는가.
- 앨범과 보트의 흔적이 다음 항해의 이유가 되는가.
- 꾸미기/상호작용이 `CHORES`보다 `내 공간` 애착으로 느껴지는가.

## PLAYER_FEEDBACK_REBUILD_LOOP

Human feedback를 다음으로 나눕니다.

```text
CALM
= 의도적으로 조용하고 머물고 싶음

EMPTY
= 할 이유나 감각적 변화가 없음

FRICTION
= 카메라/UI/입력이 감상을 방해

CHORES
= 꾸미기/펫/상호작용이 의무나 최적화로 변함

SOCIAL_PRESSURE
= 병편지가 즉답/인기/관계 유지 의무처럼 느껴짐

CONTENT_REPETITION
= 발견이 반복되어 기억되지 않음

CORE_EMOTION_FAILURE
= 기능은 있지만 편안함·잔잔함·애착이 생기지 않음
```

`EMPTY`를 해결한다고 전투, stamina, 실패, 경쟁, 점수, 광고 보상 같은 자극 시스템을 추가하지 않습니다.

## AI_VISIBLE_OUTPUT_QUALITY_GATE

향후 AI-assisted 이미지/텍스트/오디오를 실제 player-facing asset으로 쓸 경우:

```text
프로젝트 visual/audio tone
→ Bondee-inspired storybook diorama 일관성
→ 낮은 자극·가독성
→ 반복 생성 흔적/저품질 artifact 검사
→ 권리/provenance
→ 실제 3/4/감상 카메라와 5분 항해 맥락 Human review
→ accept | revise | replace
```

생성 속도나 콘텐츠 수가 quality claim이 아닙니다.

## Production AI · SILENT_OMISSION_GATE

새 content/system 추가 뒤 확인합니다.

- 발견이 GameState/album에 필요한 방식으로 기록되는가.
- Avatar/Pet/Decor와 카메라 구도를 깨뜨리지 않는가.
- companion reaction이 필요한 콘텐츠인가.
- mood 연결이 감정을 강요하지 않는가.
- 모바일 세로 UI에서 감상을 가리지 않는가.
- 꾸미기/상호작용이 파밍 최적화로 변하지 않는가.
- social을 추가할 때 승인된 delayed bottle scope를 넘어 realtime/global/public chat을 몰래 만들지 않는가.
- DriftBottle safety release gate를 우회하지 않는가.

## 승인된 온라인 범위

과거 `온라인 기능 전체 제외`는 최신 사용자 결정으로 대체되었습니다.

현재 허용하는 온라인 범위는 아래뿐입니다.

- `FriendBottle`
- `DriftBottle`
- 이를 위한 identity/auth/friendship
- moderation / Terms / report / block / 운영 도구

기본 voyage/rest/pet/decor/album/fishing/soundscape는 여전히 local-first입니다.

현재 금지:

- realtime/global/public chat
- public feed / follower / popularity score
- 위치 기반 매칭 / 데이팅
- user media attachment 기반 stranger social(MVP)
- backend 장애가 기본 휴식 플레이를 막는 구조

병편지 상세 정본은 `docs/superpowers/specs/2026-08-24-bondee-diorama-delayed-bottle-design.md`를 따릅니다.

## 적대적 검토 보호선

1. 재미 부족을 전투/실패/경쟁으로 해결하지 않는다.
2. AI 콘텐츠 수를 품질로 오인하지 않는다.
3. 꾸미기/상호작용을 chores/파밍으로 바꾸지 않는다.

5. Human 감정 evidence를 자동 테스트로 대체하지 않는다.
