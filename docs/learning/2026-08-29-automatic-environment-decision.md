# 현실 시간 분위기와 흘러가는 풍경 결정 기록

## Incident

direct boat entry 정본은 시작 전 선택을 없앴지만, 분위기를 마지막 저장값으로 둘지와 주변 배경이 실제로 어떻게 변하는지는 열어 두고 있었습니다. 이 상태로 구현하면 현실의 밤에 낮 바다가 보이거나, 구조물 풍경이 호감도·보상·방치 보상처럼 동작할 위험이 있었습니다.

## Solution

- 현지 현실 시간이 새벽·밝음·해질녘·밤의 **시각만** 자동으로 정하도록 확정했습니다.
- 저장된 분위기와 수동 시간 선택은 제거했습니다.
- 주변 풍경은 active foreground `delta`에서만 낮은 밀도로 지나가고, 구조물 탭·보상·과제·놓친 패널을 만들지 않게 했습니다.
- ambient memory는 선택적으로 자동 저장될 수 있지만 호감도나 다른 progression을 올리지 않도록 구현 계약에 분리했습니다.

## Lesson

현실 시계와 플레이 진행 시간을 같은 owner로 쓰면, 작은 시각 요구가 시간 조작 가능한 progression 또는 background-time 보상으로 변질될 수 있습니다. 시계는 표현, foreground elapsed는 현장 연출처럼 제품 의미가 다른 경우에만 분리합니다.

## Base 승격 판정

`NO_BASE_PROMOTION`입니다. 현실 시간과 바다 풍경의 의미, 낮은 발견 밀도, 기억의 비보상성은 마이 리틀 보트의 제품 고유 결정입니다. 일반적인 “system clock은 progression에 쓰지 않는다” 원칙은 이미 Godot 공식 문서와 프로젝트 작업 규칙에서 다루고 있어 새 공용 규칙으로 승격할 근거가 없습니다.
