# MVP Scope

## 핵심 경험

`오늘의 마음 선택 → 약 5분 항해 → 작은 발견/선택형 낚시 → 오늘의 기억 기록 → 앨범/동반자에 누적 → 계속 머물기 또는 다음 항해`

목표는 이기는 것이 아니라 작은 보트와 바다에 머무는 것입니다. 시스템 추가는 이 감정을 강화할 때만 허용합니다.

## 포함

- 마음 선택 4종
  - 평온
  - 지침
  - 외로움
  - 설렘
- 1인칭 보트 관조 화면
- Scene 전환에도 이어지는 5분 항해 타이머
- 사진찍기
- 실제 UI 개입을 줄이는 감상모드
- 느림 / 보통 / 빠름의 미세 표류 리듬 속도조절
- 항해 중 시간 경과로 나타나는 Ambient Discovery
  - 병 속 편지
  - 풍경 기록
- 선택형 조용한 낚시
  - 캐스팅
  - 기다림
  - 입질
  - 낚기
  - 취소 시 패널티 없음
- 오늘의 항해 기록: 완료된 항해당 정확히 1개
- 같은 실행 세션 동안 누적되는 기억
  - 사진
  - 풍경
  - 편지
  - 물고기
  - 항해 기록
- 누적 기록에 따른 동반자 호감도 Lv 1~3
- 앨범 기본 구조
  - 기록 수
  - 최근 기록

## 우선 플랫폼

- 모바일 세로 화면
- PC 마우스 입력

## 현재 Vertical Slice에서 의도적으로 미포함

- 앱 재실행을 넘는 save file persistence
- 실제 사진 PNG 저장
- 제작 아트/최종 오디오
- 어종 대량 콘텐츠
- 미끼 / 낚싯대 장비 / 줄 내구도
- 낚시 판매 / 요리 / 가격 / 경제
- 낚시 실패 패널티 / 긴장도 게이지 / 경쟁 점수
- 고급 물 셰이더

## 금지

- 전투
- 체력 / 피해 / 사망
- 실패 조건
- 경쟁 시스템
- 온라인 기능 / 온라인 편지 공유
- 로그인
- 결제
- 광고
- 런타임 생성형 AI
- 유료 에셋 의존
