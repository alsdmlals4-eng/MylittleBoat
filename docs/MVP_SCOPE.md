# MVP Scope

## 핵심 경험

`오늘의 마음 선택 → 약 5분 항해 → 잔잔한 바다/파도소리에 머물기 → 작은 발견/선택형 낚시 → 오늘의 기억 기록 → 앨범/동반자에 누적 → 계속 머물기 또는 다음 항해`

목표는 이기는 것이 아니라 작은 보트와 바다에 **쉬러 오는 것**입니다. 시스템 추가는 이 감정을 강화할 때만 허용합니다.

### Rest-first acceptance

MVP가 궁극적으로 통과해야 하는 기준:

- 아무 조작 없이도 30초 이상 머물고 싶은가.
- 음악을 끄고 파도/자연음만 들어도 공간이 성립하는가.
- 5분이 `CALM`으로 느껴지고 `EMPTY`나 `CHORES`로 변하지 않는가.
- 펫이 할 일을 만드는 존재가 아니라 곁에서 같이 쉬는 존재로 느껴지는가.
- 사진·낚시·발견을 무시해도 손해나 불안이 없는가.

이 항목은 제작 아트/오디오/펫 자산이 들어간 Human playtest 전에는 `NOT_RUN`입니다.

## 현재 구현된 Vertical Slice

- 마음 선택 4종
  - 평온
  - 지침
  - 외로움
  - 설렘
- 마음에 따라 좋고/나쁨을 판정하지 않는 미세한 하늘 톤 변화
- 1인칭 보트 관조 화면
- 모바일 세로 화면 우선 UI
- PC 마우스 드래그 + 모바일 화면 드래그 시야 회전
- Scene 전환에도 이어지는 5분 항해 타이머
- 사진찍기
- 실제 UI 개입을 줄이는 감상모드
- 느림 / 보통 / 빠름의 미세 표류 리듬 속도조절
- 항해 중 시간 경과로 나타나는 Ambient Discovery
  - 병 속 편지
  - 풍경 기록
- 선택형 조용한 낚시
  - 캐스팅
  - 기다림
  - 입질
  - 낚기
  - 취소 시 패널티 없음
  - 물고기는 앨범 기억으로 남지만 반복 낚시가 호감도 파밍 수단이 되지 않음
- 오늘의 항해 기록
  - 활성 항해에만 생성
  - 완료된 항해당 정확히 1개
  - 기록 후 계속 머물거나 `다음 항해`로 마음 선택 화면에 복귀
- 같은 실행 세션 동안 누적되는 기억
  - 사진
  - 풍경
  - 편지
  - 물고기
  - 항해 기록
- 사진·풍경·편지 기억에 따른 동반자 호감도 Lv 1~3
- 앨범 기본 구조
  - 기록 수
  - 최근 기록

## 승인된 다음 경험 방향 — 아직 runtime PASS 아님

### Wave-first soundscape

- 잔잔한 파도 `OceanBed`를 가장 중요한 소리로 둔다.
- 가까운 물결, 낮은 바람, 드문 선체 creak, 먼 자연음, 펫 foley를 낮은 밀도로 레이어링한다.
- 음악은 선택형이다. 음악 OFF에서도 5분 경험이 성립해야 한다.
- 큰 효과음/보상 징글/갑작스러운 고역을 피한다.

현재 `assets/audio`에는 production audio가 없으므로 **구현 완료로 표시하지 않는다.**

### Resting pet presence

- 펫은 바다 보기 / 앉기 / 눕기 / 졸기 / 하품·기지개 / 작은 귀·꼬리 반응을 기본 idle로 한다.
- 가끔 플레이어를 보거나 낚시를 조용히 지켜본다.
- 배고픔, 청소, 피로, 방치 패널티, 반복 터치 파밍을 만들지 않는다.

현재 제작 펫 모델/애니메이션이 없으므로 **시각/행동 품질 PASS로 표시하지 않는다.**

### Soft sea visual tone

- 안정적인 수평선
- 저~중간 대비
- 부드러운 하늘/바다 색
- 작은 고휘도 반짝임/깜빡임 억제
- 매우 작은 bob
- 낮은 빈도의 구름/원거리 생명체/펫 idle로 `EMPTY`를 방지

현재 placeholder 환경은 최종 Visual PASS가 아니다.

세부 기준: `docs/RESTING_EXPERIENCE_BIBLE.md`

## 우선 플랫폼

- 모바일 세로 화면
  - 기본 화면 드래그 입력을 기술적으로 지원
  - 실제 기기 손감각/버튼 크기/가독성은 `NOT_RUN`
- PC 마우스 입력
