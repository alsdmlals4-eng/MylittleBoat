## Main frame
Show a calm 3/4 small-boat diorama in bright gentle daylight. The player and cat rest together on the personalized boat. Include a restrained lived-in cluster such as lantern, mug, cushion/pet cushion, small plant, and optional postcard. Keep the stable horizon and broad calm sea visually more important than character beauty or decor inventory.

## UI meaning
Use only a few subtle functional affordances sufficient to communicate normal play. No dense panels, no ornate parchment theme, no tiny text. If useful, include a small Appreciation Camera inset of the same place with UI reduced and sea/horizon emphasized.

## Reading order
`my small place on the sea → player + pet resting together → soft sea/light → lived-in boat details → optional quiet interactions`

## Must communicate
- rest itself is valid play;
- avatar, pet, and pet cushion are customizable;
- customization does not imply stats, rarity, gacha, or monetization;
- Appreciation Camera is an alternate sea-focused view of the same world;
- the image is implementation guidance, not proof of runtime quality.

- sea becomes decorative background;
- UI looks like a finished complex live-service menu;
